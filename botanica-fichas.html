ÁREA DE CONOCIMIENTO

Archivo de especies

Un registro ordenado, trazable y revisable. El archivo de especies será el catálogo documental de OQTHERA Botánica. Las fichas se incorporarán cuando dispongan de identificación contrastada y referencias consultables.

← VOLVER AL ARCHIVO BOTÁNICO
01 / FUNDAMENTOS

Campos de cada ficha

Nombre científico y autoría cuando proceda; nombres comunes con su ámbito lingüístico; familia; descripción; hábitat; distribución; época de floración si está documentada; observaciones y fecha de revisión.

02 / DESARROLLO

Fotografías y derechos

Cada imagen deberá conservar su autoría, fuente, licencia y condiciones de reutilización. Una fotografía sirve como documentación visual, pero no demuestra por sí sola la identidad de un ejemplar.

03 / CRITERIOS

Estado de revisión

Las fichas distinguirán entre borrador, pendiente de revisión y revisada. No se marcará una especie como verificada sin comprobar la identificación y las fuentes.

OQTHERA / ESTADO EDITORIAL

Documentación en desarrollo

Esta página presenta el marco inicial del apartado. Las fichas específicas, claves de identificación y datos de distribución se incorporarán tras contrastarlos con bibliografía y bases de datos especializadas. No se presentan registros de especies como verificados en esta versión.
