# Security Policy

# POLÍTICA DE PRIVACIDAD
## GEOAI — Plataforma de exploración geológica

**Última actualización: 3 de noviembre de 2026**

### 1. Introducción

GEOAI es una plataforma digital educativa dedicada a la exploración, observación y estudio de rocas, minerales y fósiles.

Esta Política de Privacidad explica qué información se utiliza, cómo se almacena y qué opciones tienen los usuarios respecto a sus datos.

### 2. Responsable del proyecto

- Nombre del proyecto: GEOAI.
- Responsable:PNmonja
- Página web

### 3. Información que utiliza GEOAI

La versión actual de GEOAI permite introducir voluntariamente información sobre muestras geológicas:

- Nombre provisional de la muestra.
- Tipo de muestra.
- Color.
- Textura.
- Lugar de recogida.
- Fecha de registro.

La plataforma no solicita actualmente una cuenta de usuario ni necesita que se introduzcan datos personales para utilizar el laboratorio.

Se recomienda no introducir nombres reales, direcciones particulares, teléfonos ni otra información personal en los campos de observaciones.

### 4. Almacenamiento de la información

Las observaciones se almacenan localmente en el navegador del dispositivo mediante la tecnología LocalStorage.

Esto significa que:

- Los datos permanecen en el navegador utilizado.
- No se envían a una base de datos propia de GEOAI.
- No se sincronizan automáticamente entre dispositivos.
- Pueden perderse al borrar los datos del navegador.

Las imágenes seleccionadas se muestran mediante una vista previa local. La versión actual no incorpora un sistema propio de subida de imágenes a un servidor.

### 5. Uso de imágenes

Las imágenes seleccionadas por el usuario sirven para visualizar las muestras dentro del laboratorio.

En la versión actual no existe un modelo de inteligencia artificial conectado que analice o identifique automáticamente las imágenes.

Antes de incorporar servicios externos de análisis de imágenes, GEOAI actualizará esta política para explicar su funcionamiento y las condiciones aplicables.

### 6. Cookies y tecnologías de almacenamiento

La aplicación utiliza LocalStorage para guardar las observaciones.

LocalStorage no es una cookie, pero permite conservar información en el navegador.

GEOAI no incorpora actualmente herramientas propias de publicidad ni sistemas propios de seguimiento analítico.

El servicio de alojamiento de la página puede aplicar sus propias tecnologías y condiciones de privacidad.

### 7. Seguridad

GEOAI busca mantener una estructura sencilla y proteger la información introducida por sus usuarios.

Sin embargo, el almacenamiento local depende también de la seguridad del dispositivo y del navegador.

No se deben introducir contraseñas, información financiera ni datos personales sensibles.

### 8. Conservación y eliminación de datos

Las observaciones permanecen almacenadas en el navegador hasta que se eliminan sus datos o se borran los datos del sitio desde la configuración del navegador.

La versión actual no dispone de sincronización ni de una cuenta personal para recuperar observaciones eliminadas.

### 9. Servicios externos

La página está alojada mediante GitHub Pages.

El proveedor de alojamiento puede tratar determinados datos técnicos necesarios para prestar y proteger el servicio, conforme a sus propias condiciones y políticas de privacidad.

GEOAI no controla directamente ese tratamiento.

### 10. Derechos de los usuarios

Cuando resulte aplicable la normativa de protección de datos, los usuarios podrán ejercer los derechos que les correspondan, incluidos el acceso, rectificación, supresión y otros derechos reconocidos legalmente.

Para realizar consultas relacionadas con la privacidad se podrá utilizar el contacto indicado en el apartado 2.

### 11. Cambios en esta política

Esta política podrá actualizarse cuando GEOAI incorpore nuevas funciones, sistemas de almacenamiento, inteligencia artificial o servicios externos.

La versión actualizada se publicará en esta misma página.
