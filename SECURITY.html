Información sobre el funcionamiento y el tratamiento de datos de la plataforma.

1. Información general

3. Datos introducidos por el usuario

El laboratorio permite introducir voluntariamente información descriptiva de muestras, como su nombre, categoría, color, textura, procedencia y notas.

Se recomienda no incluir nombres de personas, direcciones particulares, teléfonos ni otros datos personales en los campos de observaciones.

4. Almacenamiento local

La versión actual utiliza LocalStorage del navegador para guardar los registros de las muestras. Estos datos permanecen en el navegador del dispositivo utilizado y no se sincronizan automáticamente con otros dispositivos.

Los registros pueden eliminarse desde la colección de GEOAI o borrando los datos del sitio en el navegador. Si se eliminan los datos del navegador, puede que no sea posible recuperarlos.

5. Imágenes

La imagen seleccionada en el laboratorio se utiliza para mostrar una vista previa local. La versión actual no incorpora un servicio propio de subida de imágenes ni un sistema de análisis automático mediante inteligencia artificial.

6. Cookies y tecnologías similares

La aplicación utiliza LocalStorage para conservar observaciones. LocalStorage no es una cookie. El proveedor de alojamiento web puede tratar datos técnicos necesarios para prestar y proteger el servicio conforme a sus propias condiciones.

7. Servicios de terceros

GEOAI está publicada mediante GitHub Pages. El alojamiento está sujeto a las condiciones y políticas de privacidad de GitHub. GEOAI no controla los tratamientos que pueda realizar el proveedor del servicio.

8. Seguridad y limitaciones

El almacenamiento local depende del navegador y del dispositivo del usuario. No debe utilizarse para guardar información sensible, contraseñas o datos financieros.

9. Derechos y consultas

Las consultas o solicitudes relacionadas con la privacidad podrán dirigirse al responsable mediante el contacto que se publique en esta página. Los derechos aplicables se atenderán conforme a la normativa de protección de datos vigente.

10. Actualizaciones

Esta política deberá revisarse cuando GEOAI incorpore cuentas de usuario, bases de datos remotas, servicios de inteligencia artificial, analítica o integraciones externas.
