Privacidad y datos

Esta página describe el funcionamiento conocido de la versión web actual. Se actualizará antes de incorporar cuentas, analítica, publicidad, pagos o servicios externos adicionales.

Ubicación

La herramienta de coordenadas solo solicita permiso cuando la persona pulsa expresamente el botón. La conversión a UTM se realiza en el navegador; esta versión no envía las coordenadas a un servidor ni las guarda en una cuenta.

Catálogo y preferencias

El catálogo científico se descarga como archivo JSON público. La versión actual no requiere crear una cuenta ni introducir datos personales para consultar sus fichas.

Servicios externos

La web puede cargar tipografías desde Google Fonts y consultar Wikimedia Commons cuando la persona utiliza la búsqueda visual. Esos servicios pueden recibir datos técnicos de conexión conforme a sus propias políticas.

Contacto y cambios

OQTHERA todavía no dispone aquí de un formulario de contacto ni de un sistema de cuentas. Antes de publicar una aplicación en tiendas se preparará una política completa con responsable, contacto, conservación de datos y requisitos de cada plataforma.
